# 手动发布的广场

所有新建文章与已有文章默认私密。作者可在文章列表或详情页点击“发布到广场”，选择技术、日常、读书、娱乐中的一类并确认发布。
广场可未登录阅读，支持标题关键词搜索、分类筛选与分页，按公开发布时间从新到旧排列。

公开内容只有文章标题、正文、作者名、广场分类和相关时间。个人分类和补记不公开，原私人接口的账号隔离规则保留。
已公开的文章修改标题、正文后会同步更新，编辑页明确提示；作者可随时在“广场设置”中撤回为私密，原文仍留在自己的日记里。

个人分类与广场分类分别保存，调整任意一项不会修改另一项。重复发布或只修改广场分类不改变首次发布时间；撤回后再发布会取得新发布时间。
保存、文件导入、修改正文与私人分类操作均不能隐式改变公开状态，公开状态只由单独的作者操作更新。

## 旧数据库升级

1. 停止应用写入，并备份数据库。
2. 现有数据库需先完成 v4，再执行一次 `database/upgrade-v5-plaza.sql`。
3. 部署配套的后端和前端后恢复服务。新数据库直接使用当前 `schema.sql`。

v5 只新增 published、plaza_category、published_time 字段、约束和索引，不更改已有正文或分类；全部旧文章的 published 为 false。
MySQL DDL 会隐式提交，因此备份和停止写入是迁移步骤。SQL 文件使用 UTF-8，Spring SQL 初始化也显式指定 UTF-8。
本轮只对备份后的本地 H2 预览数据库执行迁移，不操作公网数据库和部署。
