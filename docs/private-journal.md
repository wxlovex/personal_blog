# 从博客切换为私人日记

每个账号拥有独立的日记、分类和补记。内容权限由后端按登录身份执行，前端不承担隔离保障。
本文记录 v4 私人日记改版。v5 在保留默认私密规则的基础上增加独立广场，只有作者手动发布的文章可公开阅读，见 [广场功能说明](plaza.md)。排行榜、点赞、作者订阅和订阅文章流继续停用。

## 已有数据库升级

1. 备份数据库并停止应用写入。
2. 确认旧库已完成 v2/v3 升级，再执行 `database/upgrade-v4-private-journal.sql`，只执行一次。
3. 部署配套的后端与前端后恢复写入。

迁移将分类名称的唯一约束改为 `(user_id,name)`；原先被其他账号日记引用的共享分类，会复制到各日记所属账号并重新关联。
日记正文、时间、补记和社交历史数据均保留。旧评论中其他账号写下的内容不再对外返回，也不会作为本人的补记展示。
MySQL 的 ALTER TABLE 会隐式提交，因此升级前的备份和停止写入是实际迁移步骤。
全新数据库直接使用 `src/main/resources/db/schema.sql`，不需要重复执行升级脚本。

## 本地预览

本地预览使用独立 H2 文件库，升级前副本为 `target/ui-preview/database.before-private-journal.mv.db`。
现有预览账号保留；新注册账号从空白日记本开始，不会看到预览账号的演示记录。
服务只监听本机，前端入口仍为 `http://127.0.0.1:5173/`。

## 验证入口

- `mvn verify`：身份验证、双账号隔离、私有分类、补记、旧社交入口停用及分类迁移。
- `scripts/smoke-browser.py`：真实浏览器中的写入、编辑、补记、退出、双账号访问与响应式布局。
- `scripts/verify-ui.py`：账号切换及会话失效时清理私人页面内容。

浏览器脚本需要 Playwright 和 `BROWSER_TEST_CHROME`，可通过 `BLOG_TEST_BASE_URL` 指定本地地址。
它们只操作独立测试账号的记录；旧账号原有记录不被修改。
