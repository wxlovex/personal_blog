## 复核说明与剩余边界

- DeepSeek 复核中关于 `application.yaml` 多余 `}` 的判断是误报。实际配置为 `${TRUSTED_PROXY_PATTERN:(?!)}`，仅有一个占位符结束括号；配置绑定及真实 HTTP 回归均已通过。
- 接口保留既有正序 offset 分页。其他设备在翻页过程中删除前面内容时，仍可能产生跨请求位移；本次修复覆盖本标签页的新增与删除，不承诺多端快照一致性。游标分页属于后续接口演进。
- 代理信任使用 Java 正则，不能按原始报告中的 CIDR 示例直接填写；从右向左解析地址链的规则依据 [Tomcat RemoteIpValve 官方文档](https://tomcat.apache.org/tomcat-10.1-doc/api/org/apache/catalina/valves/RemoteIpValve.html)。不要将策略设为 `FRAMEWORK` 或信任任意来源。实际部署方法见 [安全配置说明](security.md)。
- 前端源码在仓库外的 `personal_blog_vite` 中，CI 无法读取未提交的本地源文件。部署前仍需运行同步脚本与快照检查；新增 CI 验证的是提交到 `frontend/` 的源码与生产构建。
- 未改动分页响应格式、兼容字段和旧接口参数，以保持前后端兼容；未删除点赞关系的显式清理，保留对历史数据库结构的兼容。未强制禁止本机邮件地址，以保留本地 SMTP 验收能力。
- 未连接真实 MySQL/TiDB、SMTP 或生产环境，未执行数据库迁移、依赖 CVE/镜像扫描、提交、推送或部署。代理线上配置仍需部署环境核实。
